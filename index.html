SMP NEGERI 6 MANOKWARI - Dokumen Operasional Proktor

1. Otentikasi Khusus Proktor

Akses ke dashboard dikunci secara ketat. Hanya akun Google resmi proktorsmp6@gmail.com yang diberikan hak otorisasi.

2. Operasional Scanner QR Code Physical

Buka tab Scan Kehadiran (QR). Sistem akan mengunci fokus pada input box secara otomatis. Arahkan QR Code pada kartu siswa ke alat scanner. Hasil akan muncul secara instan tanpa perlu menekan tombol keyboard atau klik mouse.

3. Pengiriman Notifikasi WhatsApp Berkelompok (Batching Queue)

Untuk mencegah nomor terdeteksi spam, sistem memproses notifikasi dalam batch 5 pesan, dilanjutkan jeda 5 menit secara otomatis.

4. Upload Data Siswa & Foto Massal

Pada tab Data Siswa, gunakan fitur Upload Excel Massal untuk mengunggah ratusan siswa sekaligus. Gunakan fitur Upload Foto Massal dengan format nama file NISN.jpg atau NISN.png untuk mencocokkan foto secara otomatis.
