📖 Panduan Penggunaan Aplikasi Absensi

Panduan lengkap operasional sistem bagi proktor dan operator sekolah SMP Negeri 6 Manokwari.

1. Login Sistem

Gunakan tombol Masuk dengan Google dan pastikan menggunakan akun resmi proktor: proktorsmp6@gmail.com. Akun lain akan ditolak secara otomatis demi keamanan sistem sekolah.

2. Penggunaan Scanner QR Code

Menu Scan Hari Ini dirancang khusus untuk scanner QR Code eksternal (hardware scanner). Scanner akan mengirimkan NISN dan otomatis menekan Enter. Sistem langsung memvalidasi anti-duplikasi, mencatat absensi, menentukan Hadir / Terlambat (batas 07:20 WIT), menampilkan foto besar siswa, dan memasukkan notifikasi ke antrean WhatsApp di background.

3. Pengelolaan Data Siswa & Upload Massal

Anda dapat mengimpor data siswa secara massal menggunakan file Excel berformat standar (download template terlebih dahulu). Foto siswa dapat diunggah massal dengan menamai file sesuai NISN (contoh: 123456789.jpg).

4. Sistem Antrean WhatsApp Otomatis

Notifikasi dikirimkan dalam batch berisi 5 pesan, kemudian sistem melakukan jeda (pause) selama 5 menit secara otomatis untuk mencegah blokir nomor WhatsApp sekolah. Semua berjalan di background tanpa mengganggu kecepatan scan proktor.

⚙️ Pengaturan Sistem & WhatsApp API

Konfigurasi endpoint API WhatsApp dan parameter operasional sekolah.
