PANDUAN OPERASIONAL PRESENSI QR CODE

SMP Negeri 6 Manokwari - Panduan Teknis Operator / Proktor

1. Penggunaan Scanner QR

• Buka menu Mode Scan QR. Pastikan kursor otomatis aktif pada kotak input scan.

• Arahkan scanner ke QR Code kartu NISN siswa.

• Sistem otomatis mendeteksi input, memeriksa anti-duplikasi, menyimpan status (HADIR/TERLAMBAT), dan memicu nada beep.

2. Aturan Waktu WIT & Cutoff

• Zona waktu aplikasi terkunci pada **WIT (Asia/Jayapura)**.

• Batas kehadiran Tepat Waktu: **07:20 WIT**.

• Scan ≤ 07:20 WIT = **HADIR** | Scan > 07:20 WIT = **TERLAMBAT**.

3. Sistem Antrean Notifikasi WA

• Pesan WhatsApp dikirim ke nomor HP Orang Tua yang terdaftar.

• Menggunakan sistem Batch (5 siswa) & Delay (5 menit) untuk mematuhi kebijakan anti-spam.

• Format kalimat bervariasi otomatis agar tidak dianggap spam.

4. Upload Massal Data & Foto

• Gunakan file Excel sesuai template untuk pendaftaran siswa massal.

• Upload foto massal wajib dinamai file sesuai NISN siswa (contoh: 123456789.jpg).
